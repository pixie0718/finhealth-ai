🏪 Real-Life Example: Raj Ka Sweet Shop

📖 Raj Ki Kahani

Raj ek chhota sweet shop khol raha hai Mumbai mein. Business achcha chal raha hai par usko Rs 5 lakh ka loan chahiye expansion ke liye. Lekin traditional banks nahi dete kyunki:

❌ Traditional Bank Ka Problem:

  • Bank pooch raha: "Audited financial statements hain?"
  • Raj: "Nahi sir, chhota business karata hoon"
  • Result: Loan Reject! (Even though profitable hai!)

✅ FinHealth-AI Ka Solution:

System automatically Raj ka data gather karta hai:

  • GST Invoice - har mahine kitna bikri hui
  • UPI Payments - customers ne kitna paisa diya
  • Bank Account - cash flow pattern
  • EPFO - agar employees hain to salary records
  • CIBIL Score - past loan history

AI Model Analysis:

  • Raj ke GST invoices 6 mahine se consistent hain ✓
  • UPI payments regular aa rahe hain ✓
  • Bank balance kabhi negative nahi ✓
  • Business 3 months mein 20% growth ✓

Final Score: 72/100 - LOAN APPROVED!

🏗️ Project Architecture

Backend (Python/FastAPI)

User Input (GST, UPI, EPFO data) ↓ Feature Engineering (ml/feature_engineering.py) ↓ ML Model XGBoost (ml/model.py) ↓ SHAP Explanations (ml/explainer.py) ↓ API Response (routers/score.py) ↓ Score: 72/100, Risk: MEDIUM, Eligible Loan: Rs 5,00,000

Frontend (React 19)

Login/Register (AuthPage.jsx) ↓ Dashboard (DashboardPage.jsx) ↓ Score Visualization (Charts + Cards) ↓ Loan Eligibility Widget ↓ Recommendations + PDF Export

Database (SQLite)

Users Table (email, password, profile) ↓ Scores Table (score history, timestamps) ↓ Consent Artifacts (AA consent records) ↓ Loan Outcomes (feedback loop)

📦 Project Components

🔐 Authentication (routers/auth.py)

MSME owner registration aur login. JWT tokens use karta hai. Business name, GSTIN, business type input leta hai.

📊 Score Calculation (routers/score.py)

XGBoost model se financial health score generate karta hai. 0-100 range mein score deta hai + risk category.

🤖 ML Model (ml/)

XGBoost trained model jo features se prediction karta hai. SHAP library se explanations generate karta hai.

📈 Feature Engineering (ml/feature_engineering.py)

Raw GST/UPI/EPFO data ko useful features mein convert karta hai. Revenue growth, cash flow, stability calculate karta hai.

🎨 Dashboard (Frontend)

React components se beautiful dashboard. Score card, charts, recommendations, loan eligibility widget display karta hai.

💬 Chat API (routers/chat.py)

Google Generative AI use karke AI chatbot. Users apne score ke baare mein poocha sakte hain.
